# TalentScout Hiring Assistant Chatbot 🤖

A Streamlit-based chatbot that collects candidate information and asks technical questions based on their tech stack using GPT.

## 🚀 Features

- Collect candidate name, email, phone, etc.
- Ask technical questions based on the candidate’s tech stack.
- Streamlit-powered clean chat interface.
- Context-aware conversation flow.
- Uses OpenAI GPT-3.5 for question generation.
